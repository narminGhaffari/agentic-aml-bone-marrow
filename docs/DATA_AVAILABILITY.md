# Data Availability Statement

Raw bone marrow whole-slide images and patient-level clinical metadata are not included in this repository because they contain protected clinical information and are subject to institutional data protection restrictions.

This repository therefore provides the source code structure, input schema, and validation workflow required to reproduce the analyses when controlled-access data are available to authorized users.

If permitted by the data governance framework, de-identified aggregate result tables may be included separately to reproduce summary statistics and manuscript figures without exposing patient-level data.
